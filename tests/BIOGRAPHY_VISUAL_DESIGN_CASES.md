# 인물 사진·장편 지면 품질 — 소형 표적 시험

| ID | 시험 | 성공 조건 |
|---|---|---|
| B01 | 나폴레옹·조제핀 각 인물 도판 | 서로 다른 사람/소장처/초상 시기·라이선스 정확히 대응 |
| B02 | 이미지의 원격 URL만 확보 | `LINK_ONLY`; 실물 파일 보존 PASS 금지 |
| B03 | 실제 파일 저장, 본문 이미지 링크 유효 | blob·링크·캡션·인물 정확성까지 재검사 |
| B04 | 인물 초상화 교환 | 피사체 오식별을 발견하는 검토 요구 |
| B05 | 후대 창작 초상 → 실제 당대 사진 오인 | FAIL |
| B06 | 권리 확인 불가 이미지 | 무단 복제 거부, 대체/불확실 보고 |
| B07 | 이미지 불러오기 실패 | `RENDER_UNKNOWN`/FAIL, HTML 정적 구문만으로 PASS 금지 |
| B08 | 정리 과정에 설명 80% 삭제 | 상세 내용 충실도 FAIL |
| B09 | 3쪽 시안 시각 품질 | 실제 지면 경계·가독성·여백·캡션·균형 검수, 장문 E2E와 분리 |
| B10 | 사용자 비저장 지시 | GitHub 쓰기 금지 우선 |

기존 모델 자동 실행/전체 E2E 검증을 소형 시안 PASS로 대체하지 않는다.
