# 중간 보고서·시각자료 보존 — 표적 회귀 시나리오 (2026-10-11)

## 변경 목적과 기준
- 운영 `main`에서 파생한 독립 개선 후보. 개발 기록 `archive/research-v2-development-20261011`은 **읽기만** 했다. 운영 `main`, `research/*`, 역사 문서는 검증 전 수정하지 않는다.
- 목적: 중간 채팅의 **조사 내용**을 W-ID 근거·핵심 그림 명세로 누적 보존하고 나중에 선택형 최종보고서로 편집·재사용한다. 단순 운영 로그와 시각 장식은 제외한다.
- 정적 계약 확인과 실제 ChatGPT 신규 스레드 모델/사용자 UI E2E는 **별도 증거**다. 이 문서만으로 E2E 성공을 주장하지 않는다.

## 실물 읽기 기준
- 실제 조사 예: `research/20261011-trump-midterms-opinion`의 Gallup 2025 및 Pew 2025~26은 서로 다른 시계열, 2025-10 공식 CPI 결측, EIA 주간 유가 수치 등. **이 예시는 파일에서 다시 확인할 수 있는 부분만** 문서·정적 사례로 사용한다.
- 실제 모델 실전 시험은 새로운 테스트 연구 브랜치에서 두 차례 유의미한 중간 보고서/그래프를 출력·저장·재조회하고, 별도 사용자 표시 기록과 실제 blob을 항목별 비교해야 한다. 거짓 자동 UI 접근·확인 불가 주장을 금지한다.

## 판정 규칙
- `STATIC PASS`: 변경 원문/링크·권한 조건·핵심 반례의 규칙 계약 검사가 충족됨.
- `GIT INTEGRATION PASS`: 실제 GitHub의 원자적 후보 커밋·HEAD/파일/blob 재조회가 성공함.
- `LIVE E2E PASS`: 별도 실제 ChatGPT 프로젝트 실행의 원문 출력/도구 호출/저장 결과/사용자 표시 가능 범위까지 직접 확인한 경우에만.
- 미실행은 `NOT RUN`, 접근 불가는 `UNKNOWN`; 개발 이력의 과거 PASS를 새 기능 성과로 재사용하지 않는다.
