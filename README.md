# General_research_GPT

개인용 범용 조사 워크스페이스의 **원본 템플릿** 저장소.

## 브랜치 운영
- `main`: 조사 규칙·보고서 양식·초기 상태 파일을 보관하는 **정본 템플릿**. 개별 조사 결과는 저장하지 않는다.
- `research/<날짜>-<주제>`: 자료 누적이 필요한 **조사 1건당 브랜치 1개**. `main`에서 분기하여 해당 브랜치 안에서 조사·검증·보고서를 완결한다.
- 브랜치의 `10_CURRENT_SUMMARY.md`, `11_DELTA_LOG.md`, `12_ARCHIVE_LOG.md`, `13_FINAL_REPORT.md`는 필요할 때만 조사용으로 사용할 수 있다. 모든 조사에 상태 갱신을 강제하지 않는다.
- 조사 종료 후 결과를 `main`에 병합하지 않는다. 브랜치 보존/삭제는 사용자가 선택하며 자동 삭제하지 않는다.
- 짧은 사실 확인이나 단순 질문에는 브랜치를 만들지 않는다.

## ChatGPT 프로젝트 연결
`PROJECT_BOOTSTRAP.md`의 내용을 ChatGPT 프로젝트 지침에 넣고 GitHub 연결을 이용한다. 필요한 규칙 파일만 읽는다.
